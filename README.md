# FIXMYCAR Twilio OTP

1. เปิด PowerShell ในโฟลเดอร์นี้
2. รัน `npm install`
3. รัน `npm start`
4. เปิด http://localhost:3000/home.html (หน้าแรกเข้าใช้งานได้โดยไม่ต้องล็อกอิน)

## ทดสอบล็อกอินโดยไม่ส่ง SMS

เพิ่มค่าจากไฟล์ `.env.example` ลงใน `.env` ที่มีอยู่ แล้วรัน `npm start`
กรอกเบอร์ทดสอบ `0000000000` และ OTP `123456` หรือเบอร์ `123-456-7890` และ OTP `000000` หน้าเว็บจะไม่ส่ง SMS จริง

โหมดนี้ใช้ได้เฉพาะเมื่อ `DEV_OTP_ENABLED=true` `DEV_OTP_ENABLED=false` และ `NODE_ENV` ไม่ใช่ `production`
กำหนดคู่เบอร์และ OTP ใน `DEV_OTP_CREDENTIALS` โดยคั่นแต่ละคู่ด้วยจุลภาค เช่น `0000000000:123456,123-456-7890:000000` ระบบรับเฉพาะเบอร์ที่กำหนดไว้ OTP ใช้ได้ครั้งเดียว หมดอายุใน 5 นาที และล็อกหลังกรอกผิด 5 ครั้ง
ห้ามใช้หรือเปิดโหมดนี้บน production

หากต้องการส่ง OTP จริง ให้ปิดหรือลบ `DEV_OTP_ENABLED` ใน `.env` และตั้งค่า Twilio credentials
สำหรับ Twilio Trial ต้องใช้เบอร์ผู้รับที่ Verified และ Verify Service ควรตั้ง OTP เป็น 6 หลัก

## กำหนดผู้ดูแลระบบ

กำหนดเบอร์โทรศัพท์ Admin ใน `.env` ด้วยตัวแปร `ADMIN_PHONES` แยกหลายเบอร์ด้วยเครื่องหมายจุลภาค
ตัวอย่าง `ADMIN_PHONES=0812345678,+66898765432` (รองรับรูปแบบเบอร์ไทย 0 นำหน้า/+66 และเบอร์ 10 หลัก/+1)
เฉพาะผู้ใช้ที่ล็อกอินด้วยเบอร์ในรายการนี้จะเห็นเมนู Dashboard และเข้าถึงหน้า/ข้อมูล Dashboard ได้
เบอร์ทดสอบที่ไม่อยู่ใน `ADMIN_PHONES` จะเป็นผู้ใช้ทั่วไป
หากไม่กำหนด `ADMIN_PHONES` จะไม่มีผู้ใช้ที่เป็น Admin และต้องรีสตาร์ตเซิร์ฟเวอร์หลังแก้ `.env`
หน้า Dashboard แสดงจำนวนผู้ใช้ ช่าง และรีวิวทั้งหมด พร้อมสรุปจำนวนรีวิวตามหมวดหมู่บริการ รวมถึงสถานะการโหลด Google Maps JavaScript API และข้อผิดพลาดการยืนยัน API key ที่ Google แจ้งกลับมา และตรวจการเชื่อมต่อ Twilio Verify
หากเปิดโหมด OTP ทดสอบ สถานะจะแสดงเป็นโหมดทดสอบ ไม่ใช่การเชื่อมต่อ SMS จริง
ใน Dashboard มีเมนู Overview สำหรับจัดการ Banner หน้าแรก (เพิ่ม แก้ไข หรือลบ โดยใช้ URL HTTPS หรือพาธรูปภาพภายในเว็บไซต์), Manage Mechanic สำหรับเพิ่ม แก้ไข หรือลบข้อมูลช่าง รวมถึงกำหนดคะแนนดาวและจำนวนรีวิวที่แสดงใน `rating-text`, และ Manage Work สำหรับจัดการตัวอย่างผลงานก่อน/หลังซ่อมและรีวิว (เพิ่ม แก้ไข หรือลบ ใช้ URL HTTPS หรือพาธรูปภาพภายในเว็บไซต์) โดยต้องเปิดเว็บผ่านเซิร์ฟเวอร์ Express ด้วย `npm start` (ค่าเริ่มต้น http://localhost:3000/dashboard.html) ไม่ใช่เปิดไฟล์หรือใช้ static preview ที่ไม่มี API
ข้อมูลช่างเดิมจากหน้าเซอร์วิสจะถูกนำเข้า SQLite อัตโนมัติเมื่อเริ่มระบบครั้งแรก และหน้าเซอร์วิสจะแสดงข้อมูลจากฐานข้อมูลเดียวกัน
ตัวอย่างผลงานเดิมจะถูกนำเข้า SQLite อัตโนมัติเมื่อเริ่มระบบครั้งแรก และ Manage Work จัดการข้อมูลที่แสดงในหน้า Work
หน้า Work โหลดรีวิวจาก SQLite และให้เฉพาะผู้ใช้ที่เข้าสู่ระบบแล้วส่งรีวิวได้ ผู้เขียนสามารถแก้ไขหรือลบรีวิวของตนเองได้ โดยเลือกรูปใหม่หรือคงรูปเดิมไว้ก็ได้ ส่วนรีวิวที่มีอยู่ก่อนเพิ่มการผูกบัญชีเจ้าของจะไม่สามารถจัดการผ่านบัญชีผู้ใช้ได้ เลือกหมวดหมู่บริการแบบไม่บังคับและแนบรูปโปรไฟล์กับรูปประกอบรีวิวได้อย่างละ 1 รูป รองรับ JPG, PNG และ WebP ขนาดไม่เกิน 2 MB ต่อรูป

Google Maps API key ตั้งค่าในตัวแปร `GOOGLE_MAPS_API_KEY` ใน `public/service.html`
ควรจำกัด key ด้วย HTTP referrer และเปิดใช้เฉพาะ Maps JavaScript API

ห้ามเผยแพร่ไฟล์ `.env` และควรเก็บ Twilio Auth Token ไว้เป็นความลับ
หาก Auth Token เคยถูกเปิดเผย ให้หมุนเวียน (Rotate) ใน Twilio Console ทันที
